The full-body portrait is used only as a CSS alpha mask and recolored in the
page palette. The avatar and ultimate icons are used inside the AGENT LINK
card and the scene slate. All agent art, names, and ability icons belong to
Riot Games; this project is an independent fan concept.

The checked-in WebP files were cropped to their alpha bounds, downscaled, and
compressed for the web. The original PNGs are not included.
